# SkyShield — Front-End Design Engineering

Sistema de Previsao e Alerta de Desastres Climaticos  
Global Solution 2026/1 — FIAP — ADS — 1TDSPX

---

## Descricao

O SkyShield e um site completo que apresenta o sistema de previsao e alerta antecipado
de desastres climaticos. O site foi desenvolvido com HTML5, CSS3 e JavaScript puro,
sem frameworks externos, seguindo as boas praticas de Front-End Design Engineering.

---

## Tecnologias Utilizadas

- HTML5 semantico
- CSS3 externo (sem CSS inline)
- JavaScript puro externo (sem frameworks)
- Responsividade com media queries
- Git e GitHub para versionamento

---
